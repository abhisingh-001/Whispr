🔐 How Secure Message works

  1. Go to Settings → Security and set a 4-6 digit PIN. This only has to be done once.
  2. While typing a message, switch on 🔐 Secure Message before hitting send.
  3. Optionally choose a self-destruct timer — it starts only after the message is unlocked.
  4. Your recipient sees a garbled 🔒 preview instead of your words.
  5. They tap the bubble and enter their own PIN to reveal it.
  6. A wrong PIN never shows a hint — it always looks the same, no matter how many attempts.
  7. Nobody, including the app's own database, ever stores your PIN or the original text.
  8. Optionally save your account password when setting a PIN to enable the Secure PIN Vault — a password-protected way to look your PIN up again if you forget it.
